大問1　質量保存則 (1)-(3)

仮定：長方形 `x_(1)<=x<=x_(2), y_(1)<=y<=y_(2)`、面外単位長さ。右面・上面は流出、左面・下面は流入。

途中式・答：蓄積率は「流入−流出」なので `partial int int rho dxdy/ partial t=-int ( rho u)_(x_(2))dy+int ( rho u)_(x_(1))dy-int ( rho v)_(y_(2))dx+int ( rho v)_(y_(1))dx`。任意領域で `partial rho / partial t+ partial ( rho u)/ partial x+ partial ( rho v)/ partial y=0`、ラグランジュ形は `D rho /Dt+ rho ( partial u/ partial x+ partial v/ partial y)=0`（一定密度なら発散ゼロ）。

大問2　傾いた一様流と二重極 (1)-(3)

仮定：`W= phi +i Psi`、`dW/dz=u-iv`、`z=re^(i theta )`。`W=Uze^(-i alpha )+(A/z)e^(i alpha )`。

途中式・答：(1) `dW/dz=Ue^(-i alpha )-Ae^(i alpha )/z^(2)`。`a= sqrt (A/U)` とすればよどみ点は `z=+-ae^(i alpha )`、座標は `(+-a cos alpha ,+-a sin alpha )`。 (2) `Psi =(Ur-A/r)sin( theta - alpha )=(U-A/r^(2))(y cos alpha -x sin alpha )`。`Psi =0` は円 `r=a` と中心を通る角度 `alpha` の直線。 (3) 一様流と二重極の重ね合わせで、円は非貫入境界となる円柱まわりの非粘性ポテンシャル流。

大問3　固体回転（強制渦）

問題・仮定：`u_(r)=0, u_(z)=0, u_( theta )=Cr`、`C>0` の軸対称流れ。

途中式・最終答：`omega _(z)=(1/r) partial (ru_( theta ))/ partial r=(1/r) partial (Cr^(2))/ partial r=2C`、他成分はゼロ。角速度 `C` の剛体回転なので強制渦（solid-body vortex）。

大問4　平板境界層のオーダー評価 (1)-(2)

仮定：代表長さ `L`、境界層厚さ `delta`、`u=O(U), v=O(V), Re=UL/ nu >>1`。標準的な平板境界層の尺度を使う。

途中式・答：連続の式 `partial u/ partial x+ partial v/ partial y=0` から `U/L∼V/delta`、従って `V/U=O(delta/L)`。運動方程式の対流項 `O(U^(2)/L)` と粘性項 `O( nu U/delta^(2))` を釣り合わせ、`delta^(2)/L^(2)∼1/Re`。最終答は `delta=O(L/ sqrt Re)`、従って `V/U=O(Re^(-1/2))`。
