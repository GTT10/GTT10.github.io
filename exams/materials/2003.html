大問 1　3本の斜材と中央材で支えられた節点

問題の読み替え

同じ長さ l、断面積 A、縦弾性係数 E、線膨張係数 alpha の棒 A, B, C。上端は同一水平面の剛体に固定され、下端 O でピン結合される。中央棒 B は鉛直、外側の棒 A, C は鉛直から theta。自重は無視する。

仮定・符号

下向きを節点変位 delta の正、棒の引張力を正とする。c = cos(theta) と置く。

導出

(1) 節点 O の下向き荷重 P。適合条件より、中央棒の伸びは delta、外側棒の伸びは delta*c。したがって N_B = EA*delta/l、N_A = N_C = EA*delta*c/l。鉛直方向の釣合いは N_B + 2*c*N_A = P。

最終結果

(1) delta = P*l/[EA*(1+2*c^2)]。応力は sigma_B = P/[A*(1+2*c^2)]、sigma_A = sigma_C = P*c/[A*(1+2*c^2)]。いずれも引張。

導出

(2) 荷重なしで全体を t だけ昇温。e = alpha*t と置く。適合条件は delta/l = e + N_B/(EA)、c*delta/l = e + N_A/(EA)。釣合いは N_B + 2*c*N_A = 0。

最終結果

(2) delta = e*l*(1+2*c)/(1+2*c^2)。sigma_B = E*e*2*c*(1-c)/(1+2*c^2)、sigma_A = sigma_C = -E*e*(1-c)/(1+2*c^2)。0<c<1 なら中央棒は引張、外側棒は圧縮。

大問 2　3点支持連続ばりと2つの集中荷重

問題の読み替え

長さ 2l、等間隔の支持 A, B, C をもつ連続ばりに、AB と BC の各中央へ下向き荷重 P。縦弾性係数 E、断面二次モーメント I。

仮定・符号

左端から右向きに x を測り、曲げモーメントは下側引張りを正とする。対称性から R_A = R_C。

導出

たわみの適合条件 y(A)=y(B)=y(C)=0 と対称条件 y'(B)=0 を、各区間で EI*y''=M(x) に代入する。AB の M(x) は 0<=x<=l/2 で R_A*x、l/2<=x<=l で R_A*x-P*(x-l/2)。右半分は対称で、l<=x<=3l/2 では R_A*x+R_B*(x-l)-P*(x-l/2)、3l/2<=x<=2l ではさらに -P*(x-3l/2) を加える。

最終結果

反力は R_A=R_C=5P/16、R_B=11P/8。曲げモーメントは A で 0、各荷重点で +5P*l/32、B で M_B=-3P*l/16、C で 0。せん断力は A から左荷重点まで +5P/16、そこから B まで -11P/16、B から右荷重点まで +11P/16、右荷重点から C まで -5P/16。

最終結果

B 点の曲げ応力を正方形断面一辺 a で評価すると、I=a^4/12、Z=I/(a/2)=a^3/6。最大値の大きさは |sigma_B|max=|M_B|/Z=9P*l/(8a^3)。

大問 3　応力と連続体の釣合い

問題の読み替え

連続体力学における力と応力の定義、英語名称、および直交座標 O-xyz に対する3次元の応力の釣合い方程式を問う。

最終結果

(1) 力は物体の運動状態を変える相互作用で、単位は N。応力は面に作用する力を面積で割った局所量で、法線成分を normal stress、接線成分を shear stress と呼ぶ。力は剛体・質点の全体量、応力は連続体内部の面ごとの分布量である。

最終結果

(2) 力 = force、応力 = stress。法線応力 = normal stress、せん断応力 = shear stress。

導出

微小要素 dx*dy*dz の各面に作用する応力を、反対面の値をテイラー展開して足し合わせる。物体力を無視すると各方向の一次項がゼロになる。

最終結果

(3) x 方向: d(sigma_x)/dx + d(tau_xy)/dy + d(tau_zx)/dz = 0。y 方向: d(tau_xy)/dx + d(sigma_y)/dy + d(tau_yz)/dz = 0。z 方向: d(tau_zx)/dx + d(tau_yz)/dy + d(sigma_z)/dz = 0。
